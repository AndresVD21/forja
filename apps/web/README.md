# @forja/web

The Next.js app (App Router, React 19, Tailwind 4). Currently a placeholder home page.

Planned layout under `src/app/`:

- `(auth)/` — sign-in
- `(app)/today/` — what the plan asks for today
- `(app)/log/` — log a workout
- `(app)/history/` — past workouts and activities
- `(app)/plan/` — create and manage the plan
- `(app)/exercises/`, `(app)/locations/`

Each route folder holds its own `page.tsx`, components and `actions.ts`.
Shared UI goes in `src/components/ui/`, auth setup in `src/lib/auth.ts`.

`AGENTS.md` here is generated by Next.js and points agents at the version-matched docs in
`node_modules/next/dist/docs/`.
